# Cake 3.0 - Cake Making Website

A modern, responsive website for showcasing and ordering custom cakes, built based on Figma design specifications.

## 📋 Project Overview

This website provides a beautiful interface for a cake business, featuring cake galleries, ordering systems, and customer information.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone http://local_proxy@127.0.0.1:39620/git/zliu31/Cake-3.0
cd Cake-3.0
```

2. Open the project:
   - For simple viewing: Open `index.html` directly in your browser
   - For development: Use a local server like Live Server, Python's HTTP server, or Node's http-server

### Running with a Local Server

**Using Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Using Node.js (http-server):**
```bash
npx http-server -p 8000
```

**Using PHP:**
```bash
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

## ⚙️ Configuration

### Color Scheme
Edit the CSS custom properties in `css/style.css` to customize the color palette:

```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
  --accent-color: #your-color;
}
```

### Content
- Update text content directly in `index.html`
- Replace images in the `images/` directory
- Modify contact information and social media links
